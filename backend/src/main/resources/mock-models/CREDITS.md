# Mock models (TRIPO_MODE=mock)

Sample GLBs returned by `MockTripoClient` instead of real Tripo output. All are CC0 1.0.
The character library in `library/` is credited model by model in `frontend/public/mock/CREDITS.md`.

| File | Used for | Source | Licence |
|---|---|---|---|
| `biped.glb` | rigged biped, 14 clips (Idle, Walking, Running, Jump, Dance, Wave, …) | "RobotExpressive" by Tomás Laulhé, modified by Don McCurdy (three.js examples, `models/gltf/RobotExpressive`) | CC0 1.0 |
| `quadruped.glb` | quadruped with one node-animation clip (`Walk`) | generated by `scripts/make-mock-glbs.mjs` (own work) | CC0 1.0 |
| `creature.glb` | static creature | generated by `scripts/make-mock-glbs.mjs` (own work) | CC0 1.0 |
| `object.glb` | static object (mushroom) | generated by `scripts/make-mock-glbs.mjs` (own work) | CC0 1.0 |

Note on `biped.glb`: the file was added without a recorded source. It was identified from its contents
(FBX2glTF export, 74 nodes, clip list `Dance, Death, Idle, Jump, No, Punch, Running, Sitting, Standing, ThumbsUp,
Walking, WalkJump, Wave, Yes`), which match RobotExpressive. Confirm before publishing the project.
